# REU Research Project: Hand Size in VR Non-Verbal Communication

## Project Overview

This repository contains the final version of a virtual reality application developed as part of a Research Experience for Undergraduates (REU) program. The project investigated the effects of hand size on non-verbal communication in virtual reality environments, resulting in a published paper in the IEEE Transactions on Visualization and Computer Graphics journal.

**Published Research**: [Does Hand Size Matter? The Effect of Avatar Hand Size on Non-verbal Communication in Virtual Reality](https://ieeexplore.ieee.org/abstract/document/10919212)

**Conference Presentation**: This research was presented at IEEE VR 2025 in St. Malo, France.

## Research Summary

This study examined how variations in virtual hand size affect users' non-verbal communication patterns and interaction experiences in VR. Through a comprehensive experiment with over 100 total participants (72 in the final analysis), we developed insights into:

- The relationship between virtual hand representations and communication effectiveness
- How hand size influences gesture usage and interpretation
- Implications for designing more inclusive and effective VR social environments

## Technical Implementation

The application was developed using:
- **Unity**: Core game engine for creating the VR environment
- **Networking**: Fully networked research environment supporting dual-user studies
- **Data Collection**: Recorded all participant's answers as well as motion data for all participants
- **VR Hardware Integration**: Support for the Meta Quest 2
